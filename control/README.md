# Control

The public/private structure is defined in [structure.json](../structure.json). Both workspaces use the same pillars and category paths; matching categories do not mean matching confidential files.

- Keep Personal, Business, and Berkeley & Education distinct.
- Keep the four business lines under Business and shared services alongside them.
- Publish only deliberately selected content with source provenance and appropriate rights.
- Preserve original project histories and licenses.
- Keep credentials, private records, unpublished manuscripts, and internal operational controls private.

The public verification script checks navigation, the declared structure, and hashes of preserved academic files. SQL examples have their own executable checks. This public page does not contain the private control system or grant automation permissions.
